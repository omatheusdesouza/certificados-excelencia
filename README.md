# Certificados – Excelência Educação

Site de consulta de certificados. A pessoa escolhe o curso, digita nome e sobrenome e baixa o certificado em PDF.

Os nomes dos participantes não ficam em texto legível nos arquivos (`cursos/*/participantes.json`).
Para incluir outro curso ou corrigir listas, use o painel de certificados e suba o ZIP gerado.
